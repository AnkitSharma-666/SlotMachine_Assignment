# 🎰 Slot Machine Game

A simple **slot machine game** built in **Unity (C#)** as part of an internship assignment.  
Enjoy smooth reel animations, randomized outcomes, sound effects, and play it directly in your browser via WebGL.

---

## 🚀 Play the Game

👉 [Play on GitHub Pages](https://ankitsharma-666.github.io/SlotMachine_Playable/)  
*No installation required — works directly in your browser!*

---

## 🕹️ Game Overview

Spin the slot machine by pulling the lever and try your luck!  

- Spend points each turn to play.  
- Match symbols to win points:  
  - **Jackpot:** All 3 symbols match.  
  - **Pair Match:** 2 symbols match (Bar, Cherry, Seven, Bell).  
- Feedback for wins/losses with animations and sound effects.  

---

## 📦 Features

- Winning logic (Jackpot + Pair Match).  
- Sequential reel animations (looping symbols for smooth visuals).  
- Randomized outcomes with fair RNG.  
- Audio feedback: BGM, spin, jackpot, normal win, no win.  
- Audio mute toggle.  
- UI updates for total points, status messages, and results.  
- Point system with play cost & rewards.  
- Delay between lever pulls to prevent spamming.

---

## 💡 Bonus Features

- Immersive sound effects + background music.  
- Audio mute toggle.  
- Delay between turns for better pacing and player experience.  

---

## 🧠 Development Approach

I focused on **building the core slot machine mechanics** first (reel spins, RNG results, payouts).  
Once the base loop worked, I added polish:  

- Smooth looping reel animations for visual appeal.  
- Clear UI feedback and point tracking.  
- Audio for immersion and player feedback.  
- Small QoL touches like mute toggle and input delay.  

This step-by-step approach ensured the game was playable early and gradually improved.
